**Cœur PUR** — la comparaison se fait sur la forme NORMALISÉE (sérialisation avant/après mutation), et
non sur le texte brut du fichier : sinon une simple différence d'indentation déclencherait une écriture
et une sauvegarde à chaque démarrage.

```csharp
/// <summary>
/// Fait converger le JSON vers l'ÉTAT DÉSIRÉ. Renvoie null si rien ne doit être écrit :
/// soit le contenu est INEXPLOITABLE (on n'y touche pas), soit il est DÉJÀ conforme.
/// Propriété testée : ReconcileJson(ReconcileJson(x)) == null (point fixe = PUR-01/02/03).
/// </summary>
public static string? ReconcileJson(string? settingsJson, string exePath, bool hooksWanted)
{
    var root = ClaudeSettingsJson.ParseOrNull(settingsJson);
    if (root is null) return null;                       // JAMAIS new JsonObject() : cela effacerait tout

    var avant = ClaudeSettingsJson.Serialize(root);      // forme normalisée AVANT mutation
    SessionHookInstaller.ApplyHooks(root, exePath, hooksWanted);
    StatusLineInstaller.ApplyStatusLine(root, exePath);  // repointe seulement ; n'installe jamais
    var apres = ClaudeSettingsJson.Serialize(root);

    return string.Equals(avant, apres, StringComparison.Ordinal) ? null : apres;
}
```

**Couche E/S** :

```csharp
/// <summary>
/// Lit, réconcilie, sauvegarde puis écrit. Renvoie true si une écriture a EU LIEU. Ne lève jamais :
/// une panne de lecture, de sauvegarde ou d'écriture dégrade silencieusement (le settings.json de
/// l'utilisateur vaut plus que la fonctionnalité).
/// </summary>
public bool Reconcile(bool hooksWanted)
{
    try
    {
        if (!File.Exists(_settingsPath)) return false;   // on ne CRÉE jamais le fichier : purge only
        var exePath = Environment.ProcessPath ?? "Chronos.exe";   // mono-fichier : jamais Assembly.Location
        var actuel = File.ReadAllText(_settingsPath);
        var reconcilie = ReconcileJson(actuel, exePath, hooksWanted);
        if (reconcilie is null) return false;            // inexploitable OU déjà conforme → rien à faire
        if (!Sauvegarder()) return false;                // échec de sauvegarde ⇒ on N'ÉCRIT PAS
        WriteAtomic(reconcilie);
        return true;
    }
    catch { return false; }
}
```

`Sauvegarder(int garder = 5)` : `Directory.CreateDirectory(_backupDir)` ;
`File.Copy(_settingsPath, Path.Combine(_backupDir, $"claude-settings-{DateTime.Now:yyyyMMdd-HHmmss}.json"), overwrite: true)` ;
puis rétention best-effort — `new DirectoryInfo(_backupDir).GetFiles("claude-settings-*.json")
.OrderByDescending(f => f.Name).Skip(garder)` avec `try { f.Delete(); } catch { }` par fichier.
Renvoie `false` si la copie échoue (l'appelant abandonne alors l'écriture), `true` sinon. La purge de
rétention, elle, n'est jamais bloquante.
