# Phase 42.2 Plan 11 : mineurs de la re-vérification du dev-council — Summary

Ce plan ferme les mineurs des deux rapports de re-vérification avant la release 3.5.0 (SEC-R1, SEC-R3, PKG-R1, DIAG-R1, FIAB-R1 à R5, plus le tri de SEC-R4) :
- un `session_id` avec un saut de ligne final est refusé ;
- un build F5, une copie temporaire ou une version plus ancienne ne reprend plus l'autostart ;
- le diagnostic ne compte plus les hooks tiers ;
- l'état d'avant Chronos des réglages Claude est épinglé ;
- une lecture inaccessible au démarrage n'écrase plus la préférence « arrière-plan » ;
- le journal d'incidents est dédoublonné et plafonné ;
- un mois gelé ne perd plus son delta ;
- les sessions archivées ne réapparaissent plus après une quarantaine.

Builds Debug et Release avec `-warnaserror` : 0 avertissement. Suite complète : 2151 tests verts, 1 ignoré (le lien symbolique, mode développeur absent).
