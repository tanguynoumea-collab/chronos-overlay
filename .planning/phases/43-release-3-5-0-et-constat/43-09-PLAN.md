## Spécification VERROUILLÉE
- Anneau extérieur = les 24 heures du jour LOCAL ; minuit en haut, sens horaire (même repère que `DayTimeline` des Anneaux :
  0° = minuit, 15° par heure). 24 braises, une par heure d'horloge : braise i = heure [i:00, i+1:00), angle nominal (i + 0,5) × 15°.
- Groupes = tranches de la grille des resets 5 h : ancre = `resets_at` 5 h COURANT (heure locale) ; la tranche d'une braise est
  `floor((centre_horaire_de_la_braise − ancre) / 5 h)` (centre = i:30 du jour local ; gère le passage de minuit). Deux braises
  voisines de tranches différentes sont séparées par un VIDE. Aucun trait, aucune flèche, aucun tiret : seul le vide délimite.
- Position : chaque braise est rapprochée du centre angulaire de SON groupe par un facteur 0,8 (angle = c + 0,8 × (nominal − c)) :
  écart intra-groupe 12°, vide entre groupes ≈ 27° (≥ 2× l'écart intra), chaque braise reste à ≤ 6° (24 min) de son heure.
  (Implémentation libre si le résultat respecte : ≤ 6° de l'heure, vide ≥ 2× écart intra, braises sans contact au rayon 66.)
- Reset 5 h INCONNU → aucune grille : 24 braises uniformes à 15° (aucun groupe inventé).
- Allumage : braise i allumée pleine si l'heure i est entièrement passée (i < floor(heures_écoulées_du_jour)), DEMI-LUEUR pour
  l'heure en cours (i == floor), cendre pour le futur. Couleur = quota 5 h (`FiveHour.ValueBrush`), Estimated (plancher « ≥ »)
  → contour pointillé comme aujourd'hui. Exemple (reset 14:50, 11:35) : groupes [00-04]=5, [05-09]=5, [10-14]=5, [15-19]=5,
  [20-23]=4 ; braises 0-10 pleines, 11 en demi-lueur, 12-23 cendre ; la tranche 09:50→14:50 montre 1 pleine + 1 demi-lueur.
- Honnêteté : seul le reset COURANT vient du serveur ; les autres limites de tranche sont PROJETÉES de 5 h en 5 h (comme la timeline
  du mode Normal des Anneaux, DS-ARCH-05). À écrire dans `docs/data-sources.md` (§ cadrans / limites) et dans le README.
- Anneau intérieur hebdo (14 braises, 7 groupes de 2, FractionElapsed) : INCHANGÉ. Centre (%, temps, « ↻ HH:MM ») : INCHANGÉ.
- Fuseau INJECTÉ (heure locale via le fuseau du VM, comme `DayTimeline`/`WindowGaugeViewModel`) ; calcul PUR testable sans fenêtre.
