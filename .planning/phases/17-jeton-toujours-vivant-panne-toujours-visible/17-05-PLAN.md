1. **Ne pas binder la pastille sur `LoginClaudeCommand`.** Cette commande BASCULE
   (`if (_oauthLogin.IsLoggedIn) _oauthLogin.Logout(); else await LoginAsync();`) et `IsLoggedIn` est
   `true` avec un jeton expiré. Un clic **supprimerait le coffre de l'utilisateur** au lieu de le
   reconnecter. D'où une commande dédiée, mono-directionnelle.
2. **Deux états visuels, pas un booléen.** « Déconnecté » est actionnable (ambre, cliquable) ;
   « hors ligne » est informatif (gris, inerte). Les confondre ferait relancer un login inutile à
   quelqu'un dont le wifi est coupé, qui échouerait — et perdrait confiance dans le signal.

    public bool LoggedIn { get; set; }
