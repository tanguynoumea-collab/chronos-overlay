<objective>
GST-02 / GST-03 (zones) — Chaque vue de cadran déclare sa silhouette de geste : une forme peinte `ZoneSilhouette` (`#01000000`),
marquée par la propriété attachée `ZoneGeste.Silhouette`, posée SOUS le contenu. Les huit silhouettes sont prouvées par rendu :
on lit l'alpha, seul critère qu'utilise Windows pour livrer un clic à une fenêtre layered.

Purpose : sur une fenêtre `AllowsTransparency`, un pixel d'alpha 0 laisse passer le clic vers le bureau ; `Transparent` rend
alpha 0 (mais WPF le dit « touché » — le piège des commentaires actuels). `#01000000` rend alpha 1, invisible, et capte.
Ce plan ne change PAS encore le routage (`CentreHit` et le `DragMove` de fenêtre restent jusqu'au plan 03).
Output : token, `Views/ZoneGeste.cs`, cinq vues à silhouette, `ZonesGesteRenduTests.cs`, deux tests existants ajustés.
</objective>
