lui-même un `WM_LBUTTONUP` pendant son appel (réentrance). Les deux se règlent dans un automate testable.

```csharp
namespace Chronos.ViewModels;

/// <summary>Nature de ce que la vue doit faire après un événement souris.</summary>
public enum TypeActionGeste { Rien, Clic, CommencerGlisser }

/// <summary>Sortie de l'automate. ClickCount n'a de sens que pour Clic.</summary>
public readonly record struct ActionGeste(TypeActionGeste Type, int ClickCount = 0)
{
    public static readonly ActionGeste Rien = new(TypeActionGeste.Rien);
    public static readonly ActionGeste CommencerGlisser = new(TypeActionGeste.CommencerGlisser);
    public static ActionGeste Clic(int clickCount) => new(TypeActionGeste.Clic, clickCount);
    public bool EstClic => Type == TypeActionGeste.Clic;
}

public enum EtatGeste { Repos, Appuye, Glisse, Consomme }

public sealed class AutomateGeste
{
    public EtatGeste Etat { get; }                                         // lecture seule publique
    public ActionGeste Appui(double x, double y, int clickCount);          // x, y en DIP (e.GetPosition)
    public ActionGeste Deplacement(double x, double y, double seuilX, double seuilY);   // seuils en DIP (SystemParameters)
    public ActionGeste Relache();
    public void PerteCapture();
}
```

Table de transitions (RESEARCH § Pattern 3) :

| Entrée | État | Sortie | Nouvel état |
|---|---|---|---|
| `Appui(x, y, n ≥ 2)` (et pas juste après un glisser) | tout état | `Clic(n)` immédiat | Consomme |
| `Appui(x, y, 1)` — ou `n ≥ 2` juste après un glisser | tout état | `Rien` (départ mémorisé = (x, y)) | Appuye |
| `Deplacement` avec `Math.Abs(x − x0) > seuilX` OU `Math.Abs(y − y0) > seuilY` | Appuye | `CommencerGlisser` | Glisse |
| `Deplacement` sous le seuil (égalité comprise) | Appuye | `Rien` | Appuye |
| `Deplacement` | Repos / Glisse / Consomme | `Rien` | inchangé |
| `Relache` | Appuye | `Clic(1)` | Repos |
| `Relache` | Repos / Glisse / Consomme | `Rien` | Repos |
| `PerteCapture` | Appuye | — (aucun clic) | Repos |
| `PerteCapture` | Glisse | — | Glisse |
| `PerteCapture` | Repos / Consomme | — | inchangé |

Drapeau « dernier geste = glisser » : levé quand `CommencerGlisser` est émis ; lu puis REMIS À ZÉRO à chaque `Appui`.
`Appui` dans n'importe quel état repart de zéro (un relâchement perdu ne bloque jamais l'automate).
